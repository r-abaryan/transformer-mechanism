# Matched multi-query feedback intervention

Frozen design before formal training, 2026-10-04. Question: does removing within-history query sampling improve fitting, compared with equally many replacement-sampled answers? Motivated by late scalar-gradient variability and incomplete all-query training fit. This changes supervision sampling, not architecture or expected objective. It tests a whole-model feedback policy, not beta-only causality.

Two paired development seeds 3461/3463, exhaustive and sampled_m arms. Same 615-parameter delta reader, initialization, original training/validation histories, history RNG seed+10000, potential-query RNG seed+20000, loads cycling 2/8/16/32, zero initial memory, 32 events per history. Both draw 64 histories with replacement per update and evaluate m answer targets per history. Exhaustive reads every present key once. Sampled_m draws m uniform present-key slots with replacement, allowing duplicates/omissions. Both consume the same potential draws; exhaustive ignores them. Pair initial/history/potential-draw hashes must match. History hashes and initial states also match the original one-query runs; their scores are historical references, not the randomized matched arm here.

Mean CE over 64*m answers gives each history and each load its original expected weight. Cache each history's prefill once in both arms; use identical read tensor shapes and optimizer settings. Adam lr .003, betas (.9,.999), epsilon 1e-8, no decay/schedule/clipping, foreach=False. CPU float64, one thread, deterministic operations. 3000 updates per run, no selection, extensions or replacements. A complete highest-load forward/backward/optimizer step in both arms on CPU and available native CUDA is profiled before freezing artifacts; formal training stays on CPU for precision/recipe continuity. Record complete-step time and CUDA allocated/reserved peaks; CPU training CUDA peaks are not applicable. GPU profiles do not establish training speed or comparative resource superiority.

Per run: 192000 history draws, 6144000 input events, 750 updates per load. Answer targets = 64*750*(2+8+16+32) = 2784000, versus historical 192000. Across four runs: 12000 updates, 768000 histories, 24576000 events, 11136000 targets. Both have 14.5 times the historical one-query answer count; shared gains cannot isolate why the old recipe failed. Paired changes in policy affect query coverage, gradient variation and subsequent joint parameters together.

Original training pools: 768 histories/load; validation: 192/load. Reserve fresh test pools: 64 base families/load x 6 value shifts = 384/load, generated with seed 2026100461, excluding all original train/validation families modulo global label shift. Labels and multiplicities are independently checked. Stable per-key assignments mean first-match retrieval is a valid task solution, not an invalid shortcut. Test uses the same 32-event lengths and loads, not length transfer. Freeze test data before training; evaluate only after all four endpoints and a pretest report/decision are locked. All arms receive full test evaluation even if fitting fails; this is an exploratory intervention with reused development seeds, not independent architecture-adoption confirmation.

Save full model/optimizer at steps 0/1000/2000/3000. Evaluate full all-query training pools there. At step 3000 also evaluate full validation/test pools. Record CE/accuracy for all/unique/repeat groups, absent groups count zero and null fields, complete-map accuracy, beta, stream/exposure hashes and every scalar alpha gradient/Adam update. Do not use the three load-32 minibatch losses as full-pool convergence evidence. Primary cell count = 4 runs x [4 snapshots x 4 training loads + 4 validation loads + 4 test loads] = 96. Target scores = 4*[4*768+192+384]*(2+8+16+32) = 846336. Final train/validation/test reports retain both seeds and every load/group.

Primary fitting benefit criterion, per seed: exhaustive load-32 training accuracy gain >=.01, CE <=.95*sampled_m CE, and no training accuracy drop >.01 at lower loads 2/8/16. Require both seeds for the declared benefit. Separately report each arm's all-seed/all-load training accuracy >=.99 gate. Threshold misses remain visible; a measured improvement can exist without crossing the benefit gate. Validation/test are descriptive and never used for tuning or seed replacement. Neither failure nor success uniquely explains every old error or supports a general architecture ranking.

Preflight exercises the actual evaluator and audit reload on initialized/intermediate saved checkpoints, all groups, supplied logits, two short actual training loops, independent labels, full-parameter gradients under both policies, duplicate/omitted-key fixtures and deliberate score/complete-map/stream/label controls. Independent gradient reference repeats histories per target and uses matrix transition equations. Freeze sources/test/protocol/preflight/profiles and parent evidence hashes before formal training. The final auditor replays every RNG draw, independently reconstructs target maps/exposures/hashes, checks all 96 cells and every scalar Adam update, and verifies reserved-data ownership and all checkpoint steps. Logits/CE <=1e-9 absolute; gradients <=1e-9+1e-7*abs(reference); scalar Adam <=1e-11. Require identical argmax. Preserve all prior evidence and stop after four runs, final evaluations, audit and documentation.

Primary sources inspected: [McCandlish et al. 2018, section 2.2](https://arxiv.org/html/1812.06162v1#S2.SS2), iid gradient means/covariance; [Yang et al. 2024, section 2.2](https://arxiv.org/html/2406.06484v2), delta correction/read and input-dependent beta. Our shared scalar compact reader differs from full DeltaNet. Conditional on one history, averaging m replacement draws retains within-query variance divided by m; exhaustive feedback removes it. This is a local application of total variance, not a paper-predicted score or optimal-batch theorem. The matched intervention can test a policy's effect under this recipe; it does not isolate Adam noise or scalar beta from all other learned parameters.
