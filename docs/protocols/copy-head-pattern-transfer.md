# Transfer the observed head-0 pattern

Frozen 2026-10-08 before scoring. Question: is the paired short-source head-0 attention pattern sufficient to recover the weak model's long-source fifth-token prediction? This tests the observed marker-reading mismatch in intact update-1,000 checkpoints.

Use cross-only seeds 3767/3779/3793 and combined 3767, update 1,000 only. Use all 128 opened ten-symbol sources, paired with their first six symbols, and identical correct decoder prefixes BOS plus first four symbols. Target is the fifth symbol. Groups all/distinct-prefix/repeated-prefix (128/10/118). No new sampling, training, head/stage search or full generation.

Three long-source modes: native, mapped head-0 pattern, wrong-position control. Map short head-0 weights at indices 0..5 to the same long indices and short EOS weight at index6 to long EOS index10; set weights6..9 to zero. Keep long-source values, head1 weights/values, output bias, encoder and decoder pre-cross states. Recompute the real downstream normalization/FFN/readout at the selected row. Control swaps the mapped weights at indices0 and10, preserving weight multiset, total mass and entropy. Index0 is a wrong marker location but can contain the correct symbol on repeated-prefix cases. The control tests this location choice, not unique marker semantics.

Report correct/EOS counts, CE, mean EOS-minus-target margin, rescues/harms by every model/group/mode. Frozen recovery: weak mapped accuracy >=95% overall. Preservation: mapped accuracy loses <=5 percentage points relative to native in every successful-control group. Specificity: weak mapped accuracy exceeds wrong-position accuracy by >=50 percentage points. Report components separately; joint support requires all three. Small group counts remain visible. These are conditional local criteria, not learned-repair or whole-sequence claims.

4 models ×3 long modes ×128 =1,536 selected long decisions per implementation. Also verify short-to-self mapping is an identity on 128 examples in each model, plus initialized fixtures. Persist logits and transferred attention weights. No terminal-EOS intervention; effects on proper stopping remain unmeasured.

Preflight: saved initialized checkpoint reload; actual producer hook and explicit downstream reference; native identity; identical short donor null; mass/nonnegativity, unchanged head1, exact mapping and control permutation; missing-group, corrupted-logit/label and wrong-marker-mapping controls. Require <=1e-9 output/reconstruction agreement and identical argmax, including archived native logits. Scalar metrics checked on reload. Protect original checkpoints, traces, source and protocol before scoring. Stop after this one transfer and control.

[Vaswani et al. (2017), section 3.2](https://arxiv.org/html/1706.03762v7#S3.SS2), inspected earlier, defines weighted values and multi-head projection. Locally, the intervention replaces `c` by `c + sum_j (a'_0j-a_0j) v_0j W_O,0^T`, retaining the output bias. This is local algebra, not a paper prediction. The supplied pattern uses the paired short input and known correspondence; it jointly changes location, mixture and sharpness relative to native attention.
