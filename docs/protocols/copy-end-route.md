# Direct source-end route diagnostic

Frozen design, 2026-10-07, before scoring. Question: does the direct end-position value contribution promote premature EOS at the weak cross-only model's first failure? This is a new authorized endpoint diagnostic, not reopening the EOS-blocking study or training.

Four saved models: cross-only 3767/3779/3793 and combined 3767. Use test10's 128 examples at the weak model's previously recorded first-failure row (positions 4/5), and at their terminal EOS row. Use test6's 128 examples at content position 4 and terminal EOS. Four models × four cohorts ×128 = 2,048 row evaluations per mode, 16 cells. All examples/pools are opened. Prefixes contain correct preceding content; at the weak model's first error these are also its native prefixes. No generation or full-copy recovery claim.

Modes: native; remove end-position contribution; remove a matched-norm position-zero contribution. Both heads contribute jointly. With native attention weights fixed, define projected position contribution `c_j = concat_h(A[h,t,j]v[h,j]) W_O^T` without output bias. End removal subtracts `c_end` from the input to decoder norm2. Control subtracts `c_0 * ||c_end||_2 / ||c_0||_2`. No clipping or selection by scores. If control norm <=1e-12, leave that control row unchanged and report it as ineligible; also report zero end norms and scaling range. Bias, other position contributions and residual are retained. Recompute norm2, FFN, norm3 and final logits. This is fixed-weight subtraction, not key masking or softmax renormalization.

Primary metrics on weak test10 first-failure rows: correct-token rescues, EOS count, EOS-minus-correct-logit margin and paired margin reductions. Report all models/cohorts and distinct/repeated groups, including absent groups. For true terminal EOS use EOS minus strongest non-EOS logit, not EOS minus itself. Report harms among native correct predictions. Operational support for an end-route-specific effect requires >=90% weak-row correct-token recovery, >=10 percentage points more recovery than the control, and greater EOS-margin reduction than control on >=90% eligible rows. Zero eligibility fails support. These practical criteria test one control, not semantic exclusivity or statistical significance. Terminal-control harms remain visible and do not silently veto or redefine the primary rule.

Preflight before execution: actual initialized saved model reload, native/reference equivalence, summed contribution reconstruction, zero-removal identity, matched norms, zero-norm behavior, supplied logits for rescue/harm and absent groups, intentional wrong-sign rejection. Producer uses hooks on the frozen native forward; reference rebuilds explicit equations and subtracts after independent per-head projection. Require <=1e-9 logit error and no argmax differences, native archived agreement, input hashes unchanged. Shared attention/projection helpers limit independence. Save logits, row indices, contribution norms/scales, metrics and verification. No gradients/training or GPU memory use.

The contribution equation is a local derivation from the inspected forward. [Newman et al. (2020), sections 1 and 3](https://arxiv.org/html/2010.07174v1#S3), inspected in the preceding review, motivates separating content and termination, not this specific route prediction. Marker information can exist at other encoder positions; zeroing/scaling contributions changes activations off their native distribution. A positive result does not explain why training learned the parameters. Stop after this one diagnostic and report; no head/position or scale sweep.
