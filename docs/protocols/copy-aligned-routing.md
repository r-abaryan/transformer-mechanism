# Is aligned cross-attention sufficient to recover long-copy content?

Frozen before evaluation, 2026-10-03. Reuse copy checkpoints 2371/2377/2381 and all eight original pools. Distinct question: does replacing learned cross-attention weights with same-position source selection recover content, after the earlier EOS/prefix diagnostic failed? No training, parameter changes, architecture comparison or fresh confirmation.

Three fixed conditions: sham retains learned cross-attention probabilities; aligned sets each content query row j<n to a one-hot source distribution at j in both heads; shifted selects (j+1)%n. Rows j>=n, including terminal EOS, retain their own native distributions. Keep encoder memory, decoder causal self-attention, projected values, output projection, residuals, normalization and FFN unchanged. Query row j predicts source[j]; decoder input is BOS plus earlier symbols. Original pools are unpadded. No direct symbol or target-vector insertion.

Evaluate complete teacher-forced logits and greedy generation for every condition. Generation suppresses only EOS during the first n outputs, using the same n+3 limit as the previous diagnostic. Report teacher content accuracy with all 16 classes and with EOS excluded, teacher content exactness, CE including terminal EOS, per-position correctness/EOS margins, and blocked-generation content/full exactness, per seed/pool/distinct-or-repeated group. The source length and alignment rule are privileged diagnostic information; these are not ordinary generation benchmarks.

Inspect native mean per-head weight at the matching source position by output position, separately from intervention effects. Attention mass alone is descriptive, not causal proof. Aligned routing may disrupt learned distributed/head-specific computations; failure cannot prove information was lost or that routing was correct. Success can establish sufficiency under this intervention, not historical failure causation or a deployable repair.

Use a native encoder/self-attention path and module-returned cross-attention weights with projected V, versus separate encoder/decoder attention, normalization and projection equations. Every teacher/probe logit agrees within 1e-9 and zero argmax changes. Sham teacher logits match archives and blocked-generation outputs match the previous copy-stopping report. Independent batched decoding uses separate candidate enumeration and prefix updates; compare all generated sequences/tokens. Separate scalar metric reductions agree within 1e-9. A position-coded value fixture detects an off-by-one selector. Shifted versus aligned must change logits >1e-6 in every seed/pool; this tests intervention effectiveness, not a requirement that shifted accuracy be lower. Save all logits, native weights, generated sequences and metrics.

Hash only relevant sources/protocols/data/reports/checkpoints before/after. Stop after three saved seeds, eight pools and three conditions, controls and one short educational report. No positional rescaling, value patch, head/token subdivision, new training or automatic extension follows a result.
