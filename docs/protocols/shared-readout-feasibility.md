# One shared classifier with the learned writer frozen

Frozen before formal evaluation, 2026-10-05. Question: can one affine six-class head classify every training read correctly while keys, value embeddings, beta and actual final memories remain unchanged?

Seeds 3461/3463, exhaustive step 12000, existing train loads 2/8/16/32. Each pool has 768 histories. All present keys are queried; 768*(2+8+16+32)=44,544 queries per seed, 89,088 total. No validation/test evaluation, new data, training, autograd or optimizer updates. Original checkpoints/reports remain unchanged. Native training accuracy/CE/complete maps and any verified witness scores are reported per seed/load and unique/repeat group. Missing groups remain null.

Store actual float64 final read vectors r=q^T S (eight coordinates), labels and source logits. Verify native Reader agreement. The feasibility claim treats these stored binary floats as exact inputs; it does not certify alternative arithmetic precision or newly computed inputs. This is a single shared head per seed, not one head or memory per history.

For phi=[r,1], seek class vectors theta_c with (theta_y-theta_c)^T phi >= gamma for every incorrect class, gamma<=1. Maximize gamma. Set theta_0=0 to remove the irrelevant common-score direction: 45 free contrast variables plus gamma. No weight/norm bound. Each seed has 222,720 class inequalities plus the margin cap. Use sparse SciPy HiGHS dual simplex, presolve, primal/dual tolerance 1e-9, maximum 100,000 iterations and 60 solver seconds. One primal solve per seed, no retries, alternate solver or tolerance changes.

Verified feasible requires native witness scoring and an independent decimal lower margin above 1e-7 for every query. A capped margin of one is not a norm optimum, CE optimum, calibrated classifier or learned repair. Witness weights are used only in a private copy of the head; the original model is preserved. No witness scores are called trained performance or transfer.

For nonpositive/numerically small primal margins, try one exact certificate reconstruction from the primal dual's positive classification multipliers, with at most 64 support rows. Solve the rational stationarity/normalization equations once using Fraction arithmetic; preserve approximate multipliers and reconstruction outcome. Accepted lambda must be nonnegative, sum to one, and cancel every class/feature coefficient exactly. Then the weighted sum of required margins is zero, excluding a strictly positive shared margin. Require a positive-supported constraint with target class greater than competitor to also exclude perfect first-index argmax via ties. A zero solver margin or small floating residual alone is not a certificate. Unsupported reconstruction, status limits/failures, or absent verified witness/certificate are unresolved. Do not claim architectural impossibility.

Independent audit: labels, affine matrix recurrence/read vectors, native scores/groups and historical baseline, actual witness head and 80-digit direct-read margins, exact rational certificate with class-wise accumulation, every solver-input row against direct class scores, counts, summary, CSV and hashes. Continuous checks 1e-9 absolute+relative; certificates exact; discrete counts exact. Producer positive margins use 60 digits and conservative 1e-45 magnitude guards, independent audit 80 digits and 1e-60 guards. Check both lower margins exceed the frozen threshold.

Preflight: known separable/contradictory features, negative free weights, sparse constraints/gauge, certificate sign/normalization/tie controls, supplied ties/absent groups, actual initialized saved evaluator/audit entry and deliberate input/read/label/certificate/head/summary defects. Fixture solver calls are separate from the two formal solves. Compilation alone is insufficient.

Stop after both solves and their audit. No norm grid, head training, architecture change, extra seed or held-out selection follows automatically. Feasible local decoding and impossible fixed-read classification have different implications; neither identifies the historical learning cause.

Primary sources inspected: [Boyd/Vandenberghe slides 5.33-5.35](https://stanford.edu/~boyd/cvxbook/bv_cvxslides.pdf), duality/alternatives; [SciPy HiGHS dual simplex](https://docs.scipy.org/doc/scipy/reference/optimize.linprog-highs-ds.html), free bounds, tolerances, statuses, marginals and limits. Our multiclass program/certificate and local scores are not published predictions.
