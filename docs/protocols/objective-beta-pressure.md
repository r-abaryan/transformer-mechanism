# Objective pressure on learned write strength

Frozen before evaluation, 2026-10-04. Question: at identical saved weights, do assigned-query and all-query losses exert different local pressure on beta? Motivated by the paired query-exposure endpoints and beta-swap effects. This diagnoses endpoint objectives; it does not reconstruct training history.

Four original delta-query-coverage checkpoints: seeds 3461/3463, fixed/resampled arms, step 3000. Original training pools only, 768 histories per load 2/8/16/32, each history 32 events. No validation/test access, new data, training, optimizer step or beta search. Load-specific cell count = 2 seeds x 2 checkpoint arms x 4 loads x 2 objectives = 32. Primary scored targets = 4 x 768 x sum(1+m for m in [2,8,16,32]) = 190464. Audit/finite-difference recomputations are correctness checks, not independent samples.

For each load use mean CE over histories for assigned queries, and mean CE over histories and all m present keys for all-query loss. Average the four load losses and gradient vectors equally to match the original uniform-load sampling. All-query loss is the expected uniform-query-resampling loss at fixed weights. One actual minibatch gradient need not equal that expectation. Report all cells and four pooled checkpoint/objective pairs.

Measure CE, accuracy, unique/repeat target counts and group CE/accuracy, alpha gradient, beta gradient, sigmoid factor, parameter-block gradient norms and assigned/all-query gradient cosines. Alpha is the trained write logit, beta=sigmoid(alpha). Derive beta gradient from alpha gradient divided by beta*(1-beta), and independently propagate the beta state derivative. Report signs: alpha gradient >1e-7 means lower-beta pressure under plain gradient descent, <-1e-7 higher, otherwise unresolved at this numerical cutoff. Opposite resolved signs identify local directional conflict. Different magnitudes with equal signs do not meet that criterion. Report every contradictory load and both seeds; no winner/adoption rule.

CPU float64, one thread, deterministic operations, batch 64 histories. Producer reuses Reader.prefill/read. Auditor uses independent matrix transitions, explicit log-partition CE, vectorized reads and an analytic state tangent for beta. Audit every native loss, prediction and parameter gradient. Logits/CE absolute tolerance 1e-9; gradients tolerance 1e-9+1e-7*abs(reference). Check beta's alpha derivative against central finite differences on the independent forward at h=1e-4 and h=5e-5; tolerance 1e-8+1e-5*abs(derivative). These are fixed numerical checks, not selected beta interventions. Undefined cosine when a norm <=1e-12 is reported as null. Missing groups have count zero and null CE/accuracy.

Before the formal run, exercise actual producer and audit reload on an initialized saved checkpoint, supplied logits, absent groups, independent labels, different batches and deliberate wrong-gradient/label/metric controls. Check the state tangent with a small analytical fixture and both finite-difference spacings. No formal checkpoint is evaluated until these pass. Freeze source/test/protocol/preflight hashes and referenced parent evidence. Retain per-target native logits/labels/groups and all gradient vectors. Compare parent CE/accuracy; verify checkpoint bytes before/after. Stop after the 32 cells, four pooled comparisons and audit. Failed checks stop the run; no automatic tuning, training continuation or replacements.

Source inspected: [Yang et al. 2024, section 2.2](https://arxiv.org/html/2406.06484v2) for correction/read and input-dependent beta. Our scalar beta and standalone tied-key reader differ from the full model. Objective averaging, tangent recurrence and sigmoid chain rule are local derivations. [Installed-version Adam equations](https://docs.pytorch.org/docs/2.11/generated/torch.optim.Adam.html) inspected to distinguish gradients from moment-dependent updates. Neither source predicts local signs or scores.
