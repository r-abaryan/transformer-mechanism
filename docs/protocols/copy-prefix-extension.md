# Matched-prefix source extension

2026-10-07, frozen before paired scoring. Question: does extending the source change early EOS preference at fixed correct decoder prefix and target? Use all 128 opened test10 rows from the positional-site study; truncate each to its first six symbols for its paired short source. No row selection or new sampling. Report duplicates and overlap with earlier short pools; do not call these fresh confirmation.

Models: cross-only 3767/3779/3793 and combined 3767. Evaluate output positions 4 and 5 separately. For 1-based position t, supply identical `[BOS]+source[:t-1]` to both sources; the correct label is source[t-1]. Source EOS moves from index6 to index10. Both branches use ordinary position IDs. No generation or retraining.

Four models × two positions × two lengths ×128 = 2,048 selected next-token evaluations per implementation; eight paired cells. Group by the six-symbol prefix being distinct or repeated; long rows are all repeated. Empty groups are null. Record all-class correctness, EOS choices, margin `z_EOS-z_correct`, paired margin difference (long minus short), correct-to-EOS and EOS-to-correct flips. Primary support: weak model at position5 has >=90% correct-to-EOS flips AND >=90% positive margin differences (>1e-10). Position4 is a declared secondary location, not a threshold-selection alternative. Report all controls regardless of the primary outcome.

Before formal scoring: synthetic metric/tie/missing-group checks, deliberately incorrect paired labels rejected, actual initialized saved-checkpoint reload with both source lengths/positions, native/reference agreement, identical-source null comparison. Audit actual outputs using explicit equations from the end-route diagnostic in native mode, independent scalar metric counts and margins, <=1e-9 error and equal argmax. Long-prefix-truncated results must agree with archived teacher-forced logits at those positions. Save logits, labels, paired metrics and source hashes. CPU float64 one thread, zero training.

Extension jointly changes suffix content, competitor count, encoder context and marker location. Even a positive result establishes only dependence on this source-extension package at a fixed decoder prefix, not pure length causality, marker-position causality or the origin of learned weights. [Newman et al. (2020), sections 1 and 3](https://arxiv.org/html/2010.07174v1#S3), inspected in prior review, motivates separating stopping from content, not these local predictions. Stop after one paired diagnostic and report; no suffix/length grid follows automatically.
