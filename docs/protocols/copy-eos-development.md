# Terminal supervision during the observed developmental window

Frozen 2026-10-08 before continuation. Does positive terminal-EOS supervision during updates 501..1,000 contribute to the weak model's growing premature-EOS behavior and head-0 marker-reading mismatch? This differs from the earlier sinusoidal, from-initialization EOS study: here marked RoPE checkpoints and the observed interval are fixed. It is not a repeat of that repair claim.

Use cross-only 3767/3779/3793 and combined 3767. From each saved update-500 checkpoint restore model, Adam moments/step and both generators. Two branches: native objective and no terminal target. Continue exactly 500 updates with original lr .001, CPU float64, one thread, same length cycle, sampled rows and positional stream. Native loss uses the unchanged executed CE path. Intervention loss is sum of content-position CE divided by original B(n+1), retaining content coefficients; EOS remains an output class and earlier optimizer history remains. This changes supervision/objective, not architecture.

Eight runs, 4,000 updates. Each computes 420,000 target rows over 79,750 sequences; content count 340,250, terminal count 79,750. Native active targets 420,000; intervention 340,250. Totals: 3,360,000 computed rows, 638,000 sequences, 3,041,000 active targets. Batch sizes210/168/140/120 for lengths3/4/5/6, no accumulation. Reuse the original complete-step profile at identical model/batches/hardware; additionally time actual initialized continuation steps and report optimizer storage. CPU peak memory unmeasured; GPU allocation/reservation inapplicable.

At the fixed final update evaluate all original ordinary and layout train/validation/test pools with existing native and independent reference evaluators: CE, content/token accuracy, full generated copying and early/on-time/late/missing EOS. No oracle content and no EOS blocking. Also evaluate the same 128 opened paired six/ten sources at fifth-token position, reporting CE/correct/EOS/margin and head-0 marker mass for all/distinct-prefix/repeated-prefix groups. Persist logits, generations, checkpoints and stream hashes. No validation selection, additional budget or replacement seed.

Frozen weak-run signatures: (1) long fifth-token correctness improves >=50 percentage points AND EOS fraction falls >=50 points relative to native continuation; (2) absolute difference in mean short/long head-0 marker mass is <=half native difference; (3) content token accuracy loses <=5 points in every nonempty ordinary short train/validation/test group. Report components separately. Joint signature requires all three. Full copying and on-time stopping are mandatory reported outcomes; even a passed signature is not a reliable repair if stopping deteriorates. Other runs are controls, not additional independent weak failures.

Preflight exercises actual saved continuation/evaluator/reference on initialized data, content/EOS gradient decomposition and unchanged content coefficients, zero terminal-logit gradient under omission, wrong-denominator rejection, labels/reload/missing-group paths. Frozen existing evaluator tests are invoked through safe helpers only. Native continuation must exactly reproduce original update-1,000 model, optimizer and generator states, with paired stream equality. Mismatch blocks historical attribution and ends the study. Keep each failed attempt; no tuning.

This intervention tests dependence on terminal supervision during one interval, conditional on earlier EOS-trained states and Adam history. It does not remove all EOS feedback: content CE still penalizes unwanted EOS. Reduced premature EOS can follow reduced stopping capability without repairing attention. Joint changes along a new trajectory do not isolate a unique mediator.

[Newman et al. (2020), sections 1/3](https://arxiv.org/html/2010.07174v1#S3), inspected in earlier copy work, motivates distinguishing termination and content. The objective weighting follows the preserved [earlier local protocol](copy-eos-training.md). The interval, restored states and signatures here are new local diagnostic choices. Stop after eight continuations and their audit.
