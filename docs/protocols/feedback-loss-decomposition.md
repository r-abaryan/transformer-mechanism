# Endpoint loss-change decomposition

Frozen before this diagnostic, 2026-10-04. Question: which prediction transitions account for higher held-out CE after continued training, and do persistent errors become more confident? Endpoint aggregate scores have already been opened. This is a descriptive diagnostic, not prospective confirmation or parameter-cause identification. Zero optimizer updates, no new training or tuning.

Use existing audited exhaustive-policy logits from steps 3000 and 12000 for seeds 3461/3463, all original full train/validation/test pools at loads 2/8/16/32. Preserve source reports, logits, data and checkpoints. Verify source audit/report/score hashes and pair canonical row/key order, labels and repeat masks. Both endpoints predict the same answers. No new pools, targets, replacements or intermediate held-out evaluation. CPU float64, one thread.

For each endpoint and answer measure CE=-log p_y, true-class probability p_y, winning confidence max_c p_c and signed true-class margin z_y-max_{c!=y} z_c. Classification uses deterministic first-index argmax. Partition each pool into correct_both, wrong_both, rescued and newly_wrong. Repeat separately for all/unique/repeat groups; absent groups have count zero and null means. Record counts, fractions, endpoint means, mean CE change and contribution to the whole relevant population's CE change. Compare increases using epsilon 1e-12 to exclude roundoff; record CE-increase count, winning-confidence-increase count, changed winning class and confidence >=.9 counts within each fixed partition. Threshold .9 is descriptive, not a calibration criterion.

For N paired answers and transition group G, contribution C_G=N^-1 sum_{i in G}(CE_new_i-CE_old_i). The four signed contributions sum to total CE change. Contributions can offset each other; do not confuse a conditional group mean with its whole-pool contribution or require positive shares to sum to 100%. Empty partitions contribute zero. Show each seed separately. At validation/test load 32, compare all four contributions and persistent-error true probability/confidence changes. This attributes a score change to answer subsets, not a learned parameter or causal training mechanism.

Save the five largest strictly positive CE changes per pool, sorted by change rounded to ten decimal places then canonical flat index. Rounding applies only to ranking numerical ties, not measured CE or group statistics. Include history index, key, label, old/new predicted class, partition and CE values, enabling inspection without duplicating input/logit files. No positivity, dominance or uniform confidence increase is assumed. Winning confidence can rise for a different wrong class; report changed-class counts. A lower p_y does not alone imply higher winning confidence or establish probabilistic calibration failure.
