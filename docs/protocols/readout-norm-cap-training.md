# Does classifier scale growth hinder learning?

Frozen before training, 2026-10-05. Hypothesis: continued radial classifier growth favors confidence changes over resolving competing reads; preventing further growth during learning improves whole-pool fitting. Earlier [scale pressure](../topics/attention/readout-scale-pressure-results.md) and [Adam transport](../topics/attention/readout-adam-transport-results.md) establish expansion, while [beta/key interventions](../topics/attention/beta-key-transport-results.md) show accuracy/CE disagreement under different readouts. None has tested this training constraint. Benefit is a hypothesis, not a predicted result.

Two original development seeds 3461/3463. Resume exhaustive-feedback model, all Adam states and exact history/query streams at step 3000. Matched arms: original control and norm cap. Both execute exactly updates 3001..4000, 64 histories/update, original 32-event histories, exhaustive queries, equal load cycling 2/8/16/32, Adam .003, betas .9/.999, epsilon 1e-8, foreach=False, no decay/schedule/gradient clipping. CPU float64, one thread, deterministic operations. Profile complete restored steps, including cap projection and existing optimizer state, before formal execution. GPU unused; allocated/reserved VRAM is null, not zero measured usage.

For augmented classifier A=[W,b], center across its six classes: C=A-mean_class(A). Fix radius R=||C_start||_F separately for each seed, using only start weights. After each Adam step, if ||C||>R, replace A with mean_class(A)+R*C/||C||. Otherwise do nothing. Only W/b change during projection; moments and all memory parameters remain untouched. Direction/common components can learn. Cap is coordinate-dependent and values can compensate by changing scale, so record value norm, beta and native train-32 centered-logit RMS. Positive projection preserves winners at that instant; subsequent gradients/trajectories can differ. No full-head freeze, moment reset, post-hoc temperature fitting or alternative radius.

Each arm executes 1,000 optimizer updates, 64,000 histories, 2,048,000 input events and 928,000 answer targets: 64*250*(2+8+16+32). Four arms total 4,000 updates, 256,000 histories, 8,192,000 events and 3,712,000 targets. These are real training executions; controls replay original-budget updates, capped branches diverge. Stop at the exact budget even if a criterion passes early.

Evaluate complete train/validation/test pools at start and final: 768/192/384 histories per load. Reuse opened original development and test pools; test results are exploratory, not fresh confirmation or selection. Save training/validation decision before test evaluation. No longer-input study: every history has 32 events. Freeze original start-error masks for train-32 and report rescues/harms, conditional error CE, and all/unique/repeat scores, including absent groups, complete maps and every seed. Six evaluated models x (768+192+384)*(2+8+16+32)=467,712 final/start answer scores in 72 cells.

Primary per-seed benefit: capped train-32 accuracy exceeds paired control by >=0.005, train-32 CE <=0.95*control CE, complete train-32 maps do not decrease, every lower-load train accuracy does not decrease, and equal-load train CE does not increase. Secondary validation preservation: no validation-load accuracy decrease and equal-load validation CE does not increase. Require both seeds for each all-seed claim. Report exact >=99% fit at every training load separately; benefit does not imply adequate fit. Test scores never enter gates. CE numerical comparisons use 1e-10 resolution; accuracy/count gates are exact.

Before training, exercise actual initialized saved training/evaluator/audit entry, independent labels/matrix gradients, supplied ties/absent cohorts, contraction/null projection controls and deliberate parameter/moment/gradient/label/logit/stream/decision/count corruption. Derive counts independently. Formal independent audit verifies every gradient and scalar Adam coordinate from the saved trace, post-step projection, model continuity, paired streams, all evaluation cells and decision. Match control final model/optimizer exactly to original step-4000 checkpoint. Exact-control failure is an implementation/fidelity defect, not a hypothesis result.

Protect scoped executed dependencies, protocols, source reports/audits/data/checkpoints and preflight/profile records. Save private traces and checkpoints under a new ignored-tensor result directory. Do not overwrite previous evidence. Stop after four runs, one audit and concise educational documentation; no radius/LR/budget grid, replacement seeds, fresh confirmation or continuation follows automatically. A positive result identifies an effect of this constraint in this window, not a unique full-history cause or architecture recommendation. A failure retains the unresolved cause. RL remains parked.
