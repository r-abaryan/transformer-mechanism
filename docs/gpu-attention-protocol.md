# RTX 4060 attention benchmark

Freeze before GPU measurements. Separate CUDA environment; preserve CPU environment and archived CPU benchmark. One head, batch1, width64, causal forward only, no gradients/dropout. Lengths512/1024/2048/4096, one fixed input seed919. Gaussian CPU inputs rounded to float16 then copied to GPU. This is an implementation benchmark, not training or an accuracy benchmark.

Three methods: explicit dense, Python-loop tiled128, and PyTorch SDPA with FLASH_ATTENTION forced and no fallback. Manual implementations cast inputs to float32 internally and return float16; fused backend uses its native accumulation. Disable TF32 for manual FP32 matmuls. Record unsupported backend/OOM as failure, not a replacement. CPU float64 attention on the same rounded inputs is the reference; predeclared max absolute error <=.005. Differences are floating-point, not a claim of bitwise equality. No direct CPU speedup comparison because dtype/implementation differ.

One process, sequential methods, rotate order with length. Five warmup forwards then ten measured forwards per cell. CUDA events measure stream elapsed time; synchronized wall timing also includes host dispatch. Synchronize before and after each sample. Delete previous outputs between samples. After warmup release unused cached allocations, record input allocation baseline and reset peak stats. Record maximum allocated and reserved PyTorch GPU bytes plus baseline-subtracted allocated peak. These exclude CUDA context and external allocations. Reference work, serialization and host/device input transfer are outside timing. Empty-cache overhead is outside samples; first measured allocation is therefore cold after warmup.

Save CPU inputs, outputs, reference, environment, all samples and memory counters. Audit saved errors/summary arithmetic/source hashes. Stop after twelve cells, with no tile tuning, clock/power changes or benchmark expansion. Laptop temperature, power and background work limit generalization; no causal explanation of timing from this matrix alone.
