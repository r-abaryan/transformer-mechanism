# Native attention backward protocol

Freeze before execution. Question: do the two working native Windows backends provide correct Q/K/V derivatives and useful forward-plus-backward performance on the existing shapes? Stop after twelve cells: dense, forced efficient, forced cuDNN at lengths 512/1024/2048/4096. No installation, architecture change or hyperparameter search.

Reuse the native forward functions, batch 1, one head, width 64, causal mask, FP16 inputs and outputs. Manual dense accumulates in FP32; TF32 disabled. CPU seed 919 generates Q/K/V as before. A separate generator with seed 929 generates a Gaussian FP16 upstream gradient G. Different lengths are separate examples. Compute the vector-Jacobian product with `autograd.grad(output, (Q,K,V), grad_outputs=G)`; mathematically this is the derivative of L=sum(G*O). No optimizer, loss scaling or parameter update.

Predeclared engineering acceptance criteria: finite output and derivatives, output max absolute error <= .005, and each Q/K/V derivative max absolute error <= .02 AND relative L2 error <= .005 against CPU float64 autograd on the same half-rounded inputs and G. Relative L2 denominator is max(reference norm, 1e-12). These tolerances test this numerical workload, not arbitrary training stability. Preserve numerical failures without relaxing criteria.

Five warmups, ten measured samples per cell, rotated method order. Each sample builds a fresh forward graph then computes all three gradients. Synchronize before and after; record CUDA events and wall time. Output/gradient release is outside timing; no gradient accumulation. After warmup release cached allocations and reset peaks. Record allocated/reserved baseline and peaks. Baseline includes live inputs and G; extra peak is not total VRAM. Exclude CPU reference, device transfers and serialization. Unsupported backend errors remain failures with no fallback.

Save all output and gradient tensors, input/G/reference, source hashes, environment, samples and counters. CPU audit independently calculates derivatives one causal row at a time: dV=A^T G; dA=G V^T; dS=A*(dA-row_sum(A*dA)); dQ=dS K/8; dK=dS^T Q/8. Verify float64 reference agreement and GPU error criteria. This independent formula catches an autograd-reference mistake without using the same backward implementation. Do not infer whole-model training speed or final accuracy.
