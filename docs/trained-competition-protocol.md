# Trained attention competition protocol

Frozen before results. New question: can changing only block-2 final-query attention weights alter long-input errors while V is fixed? This tests intervention effects, not whether distractor count originally caused each failure. Earlier Q/K donor patches changed representations; here no donor, position or value is changed.

Use all five archived deep depth-confirmation models (seeds 137/163/191/223/257) and all 1,024 archived six-pair examples. Already-opened diagnostic data, not fresh confirmation. CPU float64, frozen checkpoints, no training. Four conditions per seed: ordinary; multiply final-query scores by 2 in both heads; raise each head's true target-value-token attention mass to max(original,.9); same mass-floor intervention on the cyclic next pair's value token as a positional wrong-slot control. Record how often that control token carries the same answer. No tuning of factor, floor, head, block or token subset after results.

For selected mass p and desired p'=max(p,.9), multiply all other weights by (1-p')/(1-p), preserving their relative proportions. Keep the selected V and every other V fixed. Intervene only at the final query of block 2, after caching its original residual and Q/K/V; continue FFN, final normalization and readout normally. The target floor uses known task structure and is an oracle diagnostic, not a deployable method. Temperature scaling preserves score ordering and needs no label. Neither is equivalent to deleting real distractor tokens.

Report per-seed accuracy, cross-entropy, paired rescued/harmed counts, and attention target mass/top-rank rates. Descriptive original-error strata: target top-ranked in both heads versus not. Fixed decision for the practical factor-2 intervention: mean accuracy gain at least five percentage points AND positive gain in every seed. Failure closes this setting without trying other factors. Oracle effects establish only sufficiency under this replacement; neither success nor failure isolates softmax as the sole cause.

Verify baseline against archived metrics <=1e-10, explicit/library and sham forwards <=1e-10, unchanged checkpoint hashes, positive normalized weights, unchanged value tensors. Save final residual, scores, values, labels and all condition logits. Independently audit the final-block computation using squared-normalized weights for factor 2 and a logit-bias construction for mass floors; recompute paired metrics. Stop after twenty conditions, with no architecture proposal or further intervention sweep.
